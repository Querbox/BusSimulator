# Bus Simulator – Web-Version

Diese eigenständige Browser-Version benötigt weder Unity noch einen Build-Schritt.

```bash
npm start
```

Danach `http://localhost:4173` öffnen. Gesteuert wird mit **WASD** oder den Pfeiltasten, **Leertaste** bremst, **E** öffnet die Türen und **C** wechselt die Kamera.
